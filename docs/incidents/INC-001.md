# INC-001: FileResource no crea directorios padre inexistentes

- **ID:** MW-001
- **Fecha:** 2026-07-30
- **Estado:** Cerrado

---

## Problema detectado

`FileResource.execute('create')` fallaba con `ENOENT` cuando el directorio padre del archivo a crear no existía. También `safePath` rechazaba rutas cuyo directorio padre no existía.

## Causa raíz

`fs.writeFileSync` no crea directorios intermedios. `safePath` usaba `fs.realpathSync` sobre el directorio padre, que falla si este no existe.

## Cambio aplicado

### file-resource.ts

**execute('create'):** `fs.mkdirSync(parentDir, { recursive: true })` antes de `fs.writeFileSync`.

**safePath():** Reemplazado el bloque `catch` que rechazaba rutas con directorio padre inexistente por búsqueda del ancestro existente más cercano con validación de contención en el workspace.
